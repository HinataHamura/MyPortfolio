# Most. Atkia Farzana — Portfolio

A personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Validation

```bash
npm run lint
npx tsc --noEmit
npm run build
```

The portfolio is deployed on Vercel.
